# ASE-456

Cross Platform Development

This repository contains in-class Flutter projects from ASE-456. Each app builds on the previous one and covers a specific set of concepts.

**App 1 — Default Flutter Project**

Understanding the Android Studio workspace and navigation, learning the basics of Flutter and Dart, and running the default Flutter project.

**App 2 — Hello World**

Learning the environment file, the concept of widgets, and building a first Hello World app.

**App 3 — NKU Logo App**

Learning Scaffold, AppBar, body, and bottom bar, and building a first app that displays an image.

**App 4 — Stateless Widget**

Learning the concept of a stateless widget.

**App 5 — Dice Rolling App**

Learning functions and stateful widgets through a dice rolling app.
